# 만화 번역 · 내 서버

Chrome Manifest V3 확장 프로그램입니다. 웹 페이지의 큰 만화 `<img>`를 내 [**comic-translator**](https://github.com/furyheimdall/comic-translator) 서버에 보내 일본어 → 한국어로 번역하고, 서버가 반환한 재조판 PNG로 바꿉니다. OCR·말풍선 제거·번역·조판은 서버에서만 수행합니다. 빌드, npm 설치, 외부 라이브러리가 필요 없습니다.

| 확장 프로그램 | 필요한 서버 |
|---|---|
| 1.1.0 이상 (페어링) | comic-translator **v0.4.0 이상** |

## 설치

Chrome 웹 스토어에 등록된 확장이 아니므로 **압축해제된 확장 프로그램**으로 설치합니다. Chrome은 스토어 밖 `.crx` 파일의 직접 설치를 막기 때문에 ZIP을 풀어 로드하는 방식을 씁니다.

1. [Releases](https://github.com/furyheimdall/comic-translator-extension/releases)에서 `comic-translator-extension-<버전>.zip`을 받아, 번역에 쓸 PC의 지우지 않을 위치에 압축을 풉니다. 예: `~/Apps/comic-translator-extension`, `C:\Apps\comic-translator-extension`. Chrome은 이 폴더를 계속 읽으므로 설치 후 폴더를 옮기거나 지우면 확장이 사라집니다. 저장소를 `git clone`한 폴더를 그대로 로드해도 됩니다.
2. Chrome 120 이상(Edge·Brave 등 Chromium 계열 포함)에서 `chrome://extensions`를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램 로드**를 누르고, 압축을 푼 폴더(`manifest.json`이 들어 있는 폴더)를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 **만화 번역 · 내 서버**를 고정합니다.

업데이트: 새 ZIP을 같은 폴더에 덮어써서 풀고 `chrome://extensions`에서 이 확장의 새로고침(↻) 버튼을 누른 뒤, 번역 중이던 페이지도 새로고침합니다. 설정(서버 주소·페어링·제공자)은 유지됩니다.

Chrome을 시작할 때 “개발자 모드 확장 프로그램 사용 중지” 안내가 나올 수 있습니다. 닫으면 그대로 계속 쓸 수 있습니다.

ZIP 다시 만들기(개발자용): 이 폴더에서 `zip -X -r dist/comic-translator-extension-$(python3 -c "import json;print(json.load(open('manifest.json'))['version'])").zip manifest.json background.js content.js content.css popup.html popup.js popup.css options.html options.js README.md LICENSE`

## 서버 연결 (페어링)

1. comic-translator 서버를 실행합니다. 브라우저 컴퓨터에서 접근 가능한 주소(예: `http://192.168.0.10:18710`)를 사용합니다. 다른 컴퓨터의 서버에 연결할 때 `localhost`는 사용할 수 없습니다.
2. 서버 웹 UI에서 번역 제공자를 연결하고 실시간 번역을 지원하는 엔진(현재 Koharu)을 준비합니다.
3. 팝업의 **설정 열기**(또는 `chrome://extensions` → 세부정보 → 확장 프로그램 옵션)로 넓은 **설정 화면**을 엽니다. **서버 주소**를 넣고 **페어링 요청**을 누릅니다. **기기 이름**은 브라우저·OS로 자동 채워지며 바꿀 수 있습니다. 6자리 코드가 표시됩니다.
4. 서버 웹 UI 상단 **확장 프로그램** 화면의 **연결 요청**에서 같은 코드인지 확인하고 **승인**합니다. 요청은 5분 뒤 만료됩니다.
5. 설정 화면이 자동으로 “페어링됨”으로 바뀌고 연결 테스트를 합니다. 사람이 토큰을 다룰 필요가 없습니다. 비밀번호가 없는 서버는 페어링 없이 **연결 테스트**만 하면 됩니다.
6. 연결된 **번역 제공자**를 선택합니다. 서버에 이미 연결해 둔 제공자가 그대로 보입니다.
7. **모델**과 **추론 수준**을 고릅니다. 목록은 서버가 그 제공자에 대해 제공하는 값만 보여 줍니다. 모델은 제공자가 알려 주는 모델 목록이며, ChatGPT·SuperGrok OAuth처럼 목록을 주지 않는 제공자는 서버에 설정된 모델만 나옵니다. 추론 수준은 제공자 형식에 따라 `제공자 기본값 / 끔 / 낮음 / 보통 / 높음` 중 지원되는 것만 나옵니다. 실시간 번역은 추론을 낮추거나 끌수록 빠릅니다.
8. **설정 저장**을 누릅니다. 서버·제공자·모델·추론 설정이 다르면 서버에서 별도 세션으로 처리하며, 이전 번역 결과도 같은 제공자·모델·추론 설정일 때만 재사용합니다. 작품별 용어집은 받지 않으며, 서버가 기본 한국어 번역 지침(구어체, 말풍선에 맞는 간결한 문장, 존댓말·호칭 일관성)을 항상 적용합니다.

연결 해제:

- 서버 웹 UI **확장 프로그램 → 연결된 기기**에서 **연결 해제**하면, 이 브라우저는 다음 요청에서 연결이 끊기고 번역 중인 탭도 꺼집니다. 팝업에 다시 페어링하라는 안내가 나옵니다.
- 설정 화면의 **이 브라우저 연결 해제**는 서버의 기기 목록에서도 이 브라우저를 지웁니다.
- 서버 주소를 다른 서버로 바꾸면 기존 연결은 쓰지 않고 다시 페어링해야 합니다.

페어링으로 받은 기기 토큰은 `chrome.storage.local`에 저장되며 Chrome 계정으로 동기화되지 않고, 화면에도 표시하지 않습니다. 이 토큰으로는 확장 프로그램에 필요한 서버 기능(제공자 목록, 실시간 번역 세션과 결과 이미지)만 쓸 수 있습니다. HTTP 연결에서는 토큰과 이미지가 암호화되지 않으므로 신뢰할 수 있는 내부망, VPN 또는 HTTPS를 권장합니다. 서버가 CORS 응답 헤더를 보내지 않아도 됩니다. 모든 `/api` 호출은 백그라운드 서비스 워커에서 이루어집니다.

## 사용

- **이미지 하나만 번역**: 이미지에서 오른쪽 클릭 → **이 이미지 번역**. 탭 번역을 켜지 않아도 그 이미지만 번역해 바꿉니다. 크기 제한이 적용되지 않고, 실패한 이미지는 같은 메뉴로 다시 시도합니다. 설정이 안 되어 있으면 설정 화면이 열립니다.
- **탭 전체 번역**: 팝업에서 **이 탭 번역**을 켭니다. 오른쪽 클릭으로 일부만 번역하던 탭도 전체 번역으로 바뀝니다.
- **모든 사이트에서 항상 켜기**(팝업·설정 화면): 켜 두면 일반 웹 페이지를 열 때마다 탭 번역이 자동으로 켜져, 페이지의 만화 이미지(최소 크기 이상)를 모두 번역합니다. 주소만 바뀌는 사이트(SPA)에서 다음 화로 넘어가도 다시 켜집니다. 특정 탭만 끄려면 팝업에서 **이 탭 번역**을 끕니다(그 탭을 새로 고치거나 다른 페이지로 가면 다시 켜집니다).
- 번역 중인 이미지에는 빛이 훑고 지나가는 효과와 깜빡이는 파란 테두리, 회전 표시가 있는 **번역 중** 배지가 나타납니다. 대기 중이면 배지가 천천히 깜빡입니다. 운영체제에서 ‘동작 줄이기’를 켜면 움직임 없이 테두리만 표시합니다.
- 팝업은 현재 탭 제어와 연결 요약(서버·페어링·제공자·모델·추론)만 보여 줍니다. 모든 설정은 **설정 열기**로 여는 설정 화면에서 합니다. 설정 화면에서 **항상 번역할 사이트** 목록을 보고 지울 수 있습니다.
- **이 사이트에서 항상 켜기**는 현재 호스트명만 등록합니다. 다른 하위 도메인에는 적용되지 않습니다. 새 페이지·다른 장에서도 자동으로 켜집니다.
- 기본적으로 원본 이미지의 짧은 변이 **300픽셀 이상**, 전체 면적이 **250,000픽셀 이상**이어야 합니다. 최소 짧은 변은 설정할 수 있습니다.
- 문서 순서로 이미지를 찾고, 화면에서 약 두 화면 높이 이내에 있는 이미지만 전송합니다. 아래로 스크롤하면 다음 페이지를 자동으로 추가합니다. 지연 로딩, `srcset/currentSrc`, 열린 Shadow DOM, iframe의 `<img>`도 감지합니다.
- 이미지 모서리의 **번역 대기 / 번역 중 / 실패** 표시와 팝업의 대기·번역 중·완료·실패 수를 확인합니다. 팝업에는 서버의 작업 메시지와 오류가 표시됩니다. 툴바 배지는 미완료 이미지 수입니다.
- **원본 보기 / 번역 보기**로 현재 문서의 이미지 표시만 바꿉니다. 이미 요청한 서버 작업은 계속 진행됩니다.
- 번역을 끄면 원본으로 복구합니다. 탭 닫기·페이지 이동·새로고침에서도 해당 탭의 아직 끝나지 않은 페이지를 서버에 폐기 요청합니다. 설정의 서버·제공자·모델·추론을 변경하거나 연결이 해제되면 실행 중인 탭 번역은 꺼집니다.

페이지당 시간은 대부분 LLM 응답 시간입니다. 실측(합성 원고, DGX Spark) 기준으로 로컬 DeepSeek **추론 끔**은 첫 페이지 약 7–9초·이후 약 3–4초, 추론 높음은 페이지당 25–64초였습니다. 시간이 오래 걸려도 해당 페이지가 서버에서 완료 또는 오류 상태가 될 때까지 기다립니다. 실패한 페이지를 다시 시도하려면 번역을 껐다가 켜세요.

## 서버 API와 세션 동작

이 확장 프로그램은 실시간 페이지 추가와 아래의 **공유 세션 계약**을 지원하는 서버 버전이 필요합니다.

- `GET /api/session`, `GET /api/meta`, `GET /api/providers`
- `POST /api/live`: 동일 제공자·엔진·모델·추론 설정의 기존 세션을 재사용합니다.
- `POST /api/live/{sid}/pages`: `file`, `source_name` 멀티파트 업로드
- `GET /api/live/{sid}?pages=…`: 해당 탭의 미완료 페이지 인덱스만 조회
- `GET /api/jobs/{sid}/pages/{idx}/output`: 완성 PNG
- `POST /api/live/{sid}/discard`: `{ "pages": [인덱스, …] }`로 미착수 페이지 폐기

**`/close`는 사용하지 않습니다.** 여러 탭과 다음 장이 같은 서버 세션을 공유해 엔진을 따뜻하게 유지합니다. 확장 프로그램은 탭 및 프레임별로 페이지 소유권을 따로 관리합니다. 이미 처리 중인 페이지는 폐기 요청으로 즉시 중단되지 않을 수 있습니다. 서버 웹 UI에서 세션을 삭제해 404가 오면 세션을 다시 만들고 아직 끝나지 않은 원본을 재전송합니다. 서비스 워커 재시작 시에는 브라우저 세션 저장소의 세션 ID와 페이지 인덱스로 폴링을 이어갑니다.

동시에 두 이미지의 바이트를 준비하되 업로드 추가 순서는 유지합니다. 서버 상태는 2초 간격으로 조회하고 서비스 워커 재개용 알람을 사용합니다. GIF·AVIF·BMP 등은 브라우저에서 PNG로 변환한 뒤 업로드합니다(애니메이션 전체가 아닌 디코딩된 한 프레임).

## 제한 및 권한

- `<img>`를 기준으로 동작합니다. X처럼 그림을 CSS 배경으로 그리고 그 위에 투명한 `<img>`를 겹쳐 두는 사이트는, 같은 그림을 배경으로 그리는 주변 요소도 번역본으로 바꿉니다(사이트가 다시 그리면 3초 안에 다시 적용). `<img>` 없이 CSS 배경만 쓰는 이미지, 원본이 canvas에만 그려지는 뷰어, 닫힌 Shadow DOM, 브라우저 내부 페이지와 PDF 뷰어는 대상이 아닙니다.
- 다른 출처의 iframe은 해당 프레임 내부 화면을 기준으로 근접 여부를 판단합니다. 부모 페이지의 가시성까지 완전히 일치하지 않을 수 있습니다.
- 이미지 바이트는 HTTP(S)의 경우 백그라운드에서 로그인 쿠키를 포함해 가져옵니다. 실패하면 해당 URL에만 적용되는 임시 Referer 규칙으로 재시도한 뒤 규칙을 지웁니다. 그래도 실패하면 페이지의 원본 이미지에서 canvas 추출을 시도합니다. SameSite 쿠키, 봇 차단, 만료된 blob URL, tainted canvas 등으로 모든 방법이 실패할 수 있습니다.
- 페이지 CSP가 `blob:` 이미지를 막으면 canvas 오버레이로 표시합니다. 복잡한 변형·마스킹·겹침이 있는 특수 뷰어에서는 오버레이의 위치·클리핑이 원본과 다를 수 있습니다.
- 원본 크기가 서버 출력과 같다는 계약을 사용합니다. 자동 크기 이미지에는 필요할 때 현재 렌더링 크기를 지정하여 레이아웃 이동을 줄입니다.
- 아주 큰 이미지와 긴 data URL은 Chrome 메시지/세션 저장소 제한 및 메모리에 영향을 줄 수 있습니다. 브라우저를 완전히 재시작하면 탭의 진행 상태는 초기화됩니다. 자동 등록 사이트는 계속 저장됩니다.
- 서비스 워커가 업로드 응답을 받기 직전에 종료되면 서버에 이미 접수된 페이지가 한 번 더 추가될 수 있습니다. API에 클라이언트 업로드 식별자·멱등성 키가 없으므로 서버의 이미지 캐시를 이용합니다.
- `<all_urls>`는 이미지 다운로드·프레임 감지를 위해 필요합니다. `tabs`는 탭 활성화/종료, `storage`는 설정 및 세션 복구, `declarativeNetRequest`는 정확한 이미지 URL의 임시 Referer 설정, `alarms`는 서비스 워커 복구에 사용합니다. 다른 사이트로 이미지나 토큰을 보내는 분석/광고 기능은 없습니다.
