만화 번역 설정

일본어 → 한국어 · 내 comic-translator 서버

1. 서버 연결

페어링 상태 확인 중…

페어링을 요청하면 6자리 코드가 표시됩니다. 서버 웹 UI의 확장 프로그램 화면에서 같은 코드의 요청을 승인하세요. 서버는 언제든 이 연결을 해제할 수 있습니다. 비밀번호 없는 서버는 페어링 없이 연결 테스트만 하면 됩니다.

2. 번역 설정

서버가 이 제공자에 제공하는 모델과 추론 수준만 고를 수 있습니다. 추론을 낮출수록 빠릅니다.

탭 전체 번역은 면적 250,000픽셀 이상인 이미지만 대상으로 합니다. 이미지 오른쪽 클릭 → 이 이미지 번역은 크기와 관계없이 그 이미지만 번역합니다.

3. 자동 번역

켜 두면 일반 웹 페이지를 열 때마다 탭 번역이 자동으로 켜져, 페이지의 만화 이미지(위 최소 크기 이상)를 모두 번역합니다. 주소만 바뀌는 사이트(SPA)에서 다음 화로 넘어가도 계속 켜져 있습니다. 끄려면 팝업에서 그 탭의 번역을 끄세요.

항상 번역할 사이트

    팝업의 이 사이트에서 항상 켜기로 추가합니다. ‘모든 사이트에서 항상 켜기’가 꺼져 있을 때 이 목록의 사이트만 자동으로 켭니다.

    이미지는 내 서버로 전송됩니다. 번역 시간은 대부분 LLM 응답 시간이라 추론 수준이 낮을수록 빠릅니다.
